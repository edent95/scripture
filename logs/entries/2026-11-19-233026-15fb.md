### [E-2026-11-19-233026-15fb] 首页书目改成小红书式封面墙:手机两列、宽屏三列瀑布流,每本书一张大字封面

- **type**: feat
- **scope**: scripts/build.mjs, scripts/emblems.mjs, scripts/scenes.mjs, src/styles.css, src/app.js, tests/site.test.mjs
- **impact**: 用户问「经书的排版可以做小红书瀑布流?」。首页 24 本书原来是一行一张(手机)的灰底卡片,现在是封面墙:每本书一张封面(纯色墨底 + 传统 + 大字书名 + 这本书自己的主题线稿放大出血),封面下面不带卡片框,自由排原文书名、两行简介、章段数和阅读进度。手机一屏能看到 2–4 本,原来只有 1 本多。中英两版都改;章节目录页和读经页没动。
- **changed**: (1) build.mjs 的 bookCard 重写:`a.feed-item > div.feed-art[data-layout][data-pattern] > img.feed-scene + .feed-copy(期号 No.xx、传统、h3.feed-title、印章)`,下面是 `.sa-name / p / small`;英文首页「Chinese only」那组也走同一个 bookCard(pending 参数)。墨色 6 种(emblems.mjs 的 COVER_TONES)、版式 4 种、底纹 5 种、封面比例 6 种,都按书在全站的顺序 n 取模,写成行内样式。书名字号按字数分档(cqi)。印章中文版是「梵 / 巴」(原文语言),英文版是 SKT / PALI,只在版式 2、3 出现。(2) scenes.mjs:sceneSvg 的 palette 可以传对象;新增 coverSceneSvg,静止版、按封面墨色上色(paper = 封面底色)、线宽 ×1.5 并加 `vector-effect: non-scaling-stroke`;emblems.mjs 的 writeCovers 写出 `covers/<slug>.svg`。(3) styles.css:`.book-list` 的旧卡片样式全部换成 `.feed-*`;和 `.chapter-list` 合写的选择器拆开;右上角小花纹章(.card-emblem)从首页书卡拿掉。(4) app.js 末尾新增一段:把每个 `ul.book-list` 换成 `div.book-list.feed`,书卡按 i % N 分进 N 个 `ul.feed-col`(≥1000px 三列,否则两列,监听 matchMedia change);续读按钮取书名的选择器从 `strong` 改成 `.feed-title`。
- **ripples**: (1) 首页书卡的结构和 class 全变了:`.book-list strong`、`.card-emblem` 不存在了,书名在 `h3.feed-title`。(2) 有 JS 时 `.book-list` 是 div、书卡在 `.book-list > ul.feed-col > li`,不再是 `ul.book-list > li`;分列必须排在「搬书架」那段之后(测试钉了顺序)。(3) 封面墨色绑在书的顺序上:在 content 里中间插一本新书,后面所有书的封面颜色、版式、期号都会跟着变;新书要有 scenes.mjs 的主题插画(SUBJECTS),否则 writeCovers 报错。(4) 封面是图片,深色模式不跟着变,这是有意的。(5) emblems/<slug>-*-still.svg 首页不再用(书页的首屏仍在用会动的版本),文件照旧生成。(6) 加第三种语言时补 SEAL 表和 titleSize 的字号档。
- **verified**: `npm run check` 14 项测试通过、构建 352 页。CDP 模拟 375×667(中、英首页)与 1280×800 看过截图:两列 / 三列错落,书名、期号、印章、线稿都在封面内,页面没有横向溢出(只有封面里故意出血的线稿超出,被封面自己裁掉)。预置阅读记录后:续读按钮文字正确,「在读 1+1 / 佛经 6+6 / 巴利文经典 3+2 / 印度经典 2+2 / 读完了 1」各自分列,进度胶囊在封面下面。没在真机上看;浅色模式、320 宽、没读过任何书以外的英文长书名(最长 67 个字符,7.2cqi 字号)只靠规则推,没逐张看。
- **keywords**: 小红书, 瀑布流, 封面墙, masonry, feed, 封面, 首页, 书卡, cqi, container query, non-scaling-stroke, COVER_TONES
- **learned**: [skill:xhs-cover-feed] 没有 React 的静态站也能照做:构建时把墨色 / 版式 / 底纹 / 比例按序号写成行内样式和 data 属性,瀑布流用二十行原生 JS 把 li 按 i % N 分进 N 个 ul;没有 JS 时退回普通网格。线稿如果是独立 SVG 文件(用 img 引),CSS 管不到里面,要在生成时把 `<style>*{vector-effect:non-scaling-stroke}</style>` 写进 SVG 并把颜色烤进去。 [knowledge] `container-type: inline-size` 的元素自己用 cqi 是按「上一层容器」算的,不是按它自己;封面自己的 padding 不能用 cqi,要放到里面一层(子元素与 ::before/::after 才按它算)。
