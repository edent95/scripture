### [E-2026-11-18-231625-6143] 五部经加英译，网站分成中英两版，右上角 EN | 中文 一键切换
- **type**: feat
- **scope**: client
- **impact**: cross-cutting
- **changed**:
  - `translations/en/*.json`：心经、金刚经、阿弥陀经、薄伽梵歌、瑜伽经共 1,021 段英译（从梵文直译），486 条三语对照注（中文 `note` + 英文 `en`），每部书中英两份「差在哪」总结（`compare` / `compareEn`）
  - `scripts/content.mjs`：`mergeEnglish()` 按梵文指纹 `h`（`sa.tr` 的 sha1 前 8 位）把英译叠到 content 上，章数 / 段数 / 指纹对不上就报错
  - `scripts/build.mjs`：重写成按语言出两套页（`/…` 中文、`/en/…` 英文），`T` 表放界面文字，`langToggle()` 出右上角胶囊，写 hreflang；两版各只用自己的语言
  - `scripts/en-skeleton.mjs`：打印带指纹的底稿，给后面补英译用
  - `src/app.js`：栏目开关按语言分别记忆（`scripture.cols.v3.<lang>`）
  - `src/styles.css`：`.lang-toggle` / `.lang-option`（跟 eden-tan.com 一样，选中的是主品牌色胶囊）、英文栏、三语对照、总结区
  - `scripts/serve.mjs`：预览也监视 `translations/`
  - `AGENTS.md`：新增「多语言规则」——以后加任何语言都照英文版的格式
- **ripples**:
  - 面板重新导入（`scripts/import-dashboard.mjs`）后，某段梵文 `sa.tr` 一变，`translations/en/<slug>.json` 那一段的指纹就对不上，`npm run check` 直接失败；那一段英译要重译，不能只改 `h`
  - 中文版不放英文、英文版不放中文：以后往页面加任何文字都要进 `build.mjs` 的 `T` 表两份，不能只写一种语言
  - 英文版只出有英译的书；法华经、楞伽经、维摩诘经、无量寿经在英文首页列为 Chinese only，书名简介写在 `build.mjs` 的 `EN_PENDING`，补完英译后要从那里删掉
  - `build.mjs` 只认 `zh` / `en`；加第三种语言要先把写死的 `en` 抽成按语言循环
- **verified**: `npm run check` 7 项全过（含英译指纹 / 段数、英文页段数、语言切换指向对应页、两版不夹另一种语言的栏）；扫 `dist/en` 除三语对照注引原词和切换钮外没有中文
