## 2026-11-19

### [E-2026-11-19-222243-afd6] SEO：经文页 description 改成「这页给你什么」，英文标题用通行名（Heart Sutra、Bhagavad Gita…）

- **type**: feat
- **scope**: scripts/build.mjs, tests/site.test.mjs
- **impact**: 330 个经文页的 meta description 以前直接截第一段经文（「嗡！礼敬神圣的……」「我是这样听说的……」），搜索结果里看不出这页是干什么的；现在先写书名 / 章名 + 原文语言 + 白话直译 + 古译对照 + 段数，再接单章书的简介或多章书的开头。英文版 <title> 与 description 改用大家搜的名字（Heart Sutra、Diamond Sutra、Bhagavad Gita、Metta Sutta、Mulamadhyamakakarika 等，表在 EN_SEARCH_NAME），页面上的书名照旧用直译名。英文目录页标题去掉了「plain English and Chinese side by side」（英文版并不放中文）。
- **changed**: 新增 chapterDescription()、enSearchName()、EN_SEARCH_NAME；chapterPage 与 bookIndexPage 的英文 title 改用 enSearchName；加一条测试：描述各不相同、不以经文开头、长度 ≤ 140/160，英文心经标题以 Heart Sutra 开头。
- **ripples**: 新增英译书时，如果英文直译书名里没有大家搜的通行名，要在 EN_SEARCH_NAME 补一行，否则英文标题会落回直译名。加第三种语言时 chapterDescription 也要按语言补一套。效果要等 GSC 接上后看点击率（面板 seo-overview 里 Scripture 还是 missing，要先在面板登记站点、GSC 加属性提交 sitemap）。
- **verified**: npm run check 通过（12 项、352 页）；抽查 dist 的 /heart-sutra/、/en/heart-sutra/、/lotus-sutra/2/、/en/bhagavad-gita/3/、/dhammapada/1/ 的 title 与 description。
- **keywords**: SEO, meta description, title, Heart Sutra, Bhagavad Gita, 通行名, 搜索结果
- **learned**:
  - [skill:seo-combo] 直译站的英文书名（The Heart of the Perfection of Wisdom）和用户搜的词（Heart Sutra）常常不一样，<title> 要用搜索名，页面正文保留直译名，两边都不牺牲。
