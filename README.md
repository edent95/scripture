# scripture.eden-tan.com

经书白话直译：让现代人看得懂以前的经书。从梵文、巴利文、文言、希腊文、阿拉伯文直译成白话，逐段对照原文与玄奘、鸠摩罗什等古译。

- 收 31 部（个人面板书库「梵文」「巴利文」「文言」「希腊文」「阿拉伯文」书架）：
  - 佛经（梵文）：心经、金刚经、大悲咒、阿弥陀经、药师经、普贤行愿品偈、无量寿经、法华经、维摩诘经、楞伽经、中论颂、唯识三十颂、唯识二十论、因明入正理论、佛所行赞
  - 巴利文经典：慈经、吉祥经、转法轮经、大念处经、法句经
  - 印度经典：薄伽梵歌、瑜伽经、数论颂、奥义书三篇（伊莎、蛙氏、羯陀）
  - 中国经典：道德经（王弼本，81 章）
  - 基督教经典：圣经分卷、分批做，已收《马可福音》（16 章 678 节，`/mark/<章号>/`）、《马太福音》（28 章 1071 节，`/matthew/<章号>/`）、《路加福音》（24 章 1151 节，`/luke/<章号>/`）、《约翰福音》（21 章 879 节，`/john/<章号>/`），四卷福音书齐了；《使徒行传》（28 章 1006 节，`/acts/<章号>/`）；希腊文 SBLGNT + 和合本对照
  - 伊斯兰经典：古兰经（分批做，已收开端章和第 30 卷，即第 1、78–114 章，共 38 章 571 节；`/quran/<章号>/`）
- 英译（从梵文、巴利文、文言、希腊文、阿拉伯文直译，逐段标出英文、中文、原文的差别）：31 部全部，放在 `translations/en/`；英文版在 `/en/`，右上角 EN | 中文 切换
- `node scripts/import-dashboard.mjs` 从面板书库重新导入，`npm run dev` 本地预览，`npm run check` 测试 + 构建
- 规矩见 `AGENTS.md`
