# scripture.eden-tan.com

梵文经书白话直译：从梵文直译成白话，逐段对照玄奘、鸠摩罗什等古译，附天城体原文与罗马转写。

- 收：心经、金刚经、阿弥陀经、无量寿经、法华经、维摩诘经、楞伽经、薄伽梵歌、瑜伽经（个人面板书库「梵文」书架）
- 英译（从梵文直译，逐段标出英文、中文、梵文的差别）：心经、金刚经、阿弥陀经、薄伽梵歌、瑜伽经，放在 `translations/en/`
- `node scripts/import-dashboard.mjs` 从面板书库重新导入，`npm run dev` 本地预览，`npm run check` 测试 + 构建
- 规矩见 `AGENTS.md`
