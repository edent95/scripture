# 白话准则

这份准则管本站所有中文白话：经文的译文、每章的「这一章在讲什么」、每部书的「读之前先知道这几件事」。
写新内容、重写旧译文之前先读一遍；写完用最后一节的清单自查。

来由：用户 2026-11-21 看了第一版古兰经说「我想要的是白话文，我还是看不懂」，2026-11-25 再次说明要「没有背景也可以读懂的那种」。

## 1. 给谁看，怎样算合格

读者是**完全没接触过这部经、也没接触过这个宗教的人**：不认识人名，不知道术语，不知道当时发生了什么。

合格的标准只有一条：**这个人读一遍，说得出这一段在讲什么。**

把原文的字逐个换成现代汉语不算白话。「谁以毫不动摇的虔爱瑜伽侍奉我，他就超越了这三德，够格成为梵」每个字都是现代汉语，没背景的人还是读不懂。

## 2. 译文怎么写

1. **用平常说话的词。** 像跟朋友讲，不用文言，不用佛学院或教科书的腔调。「安住」写成「把心安放好」，「示现」写成「显出……的样子」。
2. **句子写完整。** 原文省掉的主语、宾语补上。偈颂不用硬凑成诗，写成通顺的句子。
3. **说清谁在对谁说。** 一段话是谁说的、对谁说的，开头就交代，如「（阿周那问：）」。一章里换了说话人，换的地方要标。
4. **一段对一段，不增不减。** 每段白话对应原文的一段，不合并、不拆开、不跳过、不调换顺序（英译靠原文指纹逐段对齐）。原文重复的地方照样重复。
5. **不改意思，不加立场。** 不替经文辩护，不批评，不说「这其实是比喻」这类评判，除非原文自己这么说。原文有歧义、学界读法不一的，译文取最通行的一种，别的读法写进注里。
6. **数字、人名、地名照原文。** 人名第一次出现时加一句身份，见下面的括号规则。

## 3. 括号：补的字和经文分开

原文没有、但不补就看不懂的字，放进圆括号（）。读者由此知道哪些是经文、哪些是本站补的。

- **补什么**：省略的主语和宾语；代词指的是谁；人名的身份「须菩提（佛的弟子）」；术语的白话意思。
- **不补什么**：自己的评论、引申、修行建议。
- **长度**：一个括号尽量不超过十五个字。说不完的放进「常见的词」，括号里只留最短的一句。
- **频率**：同一个括号说明一章里只出现一次（第一次出现的地方），不要每次都带。
- **不确定的不硬补**：原词意思不明就照实写「（意思不明）」，像大悲咒现在的做法。

## 4. 术语

佛教、印度教、伊斯兰教的专门词，读者以后在别处还会遇到，所以**保留通行的叫法，第一次出现时用括号给白话意思**，句子的主干仍然用平常话。

| 不合格 | 合格 |
|---|---|
| 他就超越了这三德，够格成为梵。 | 他就不再被三德（人身上的三种天性）牵着走，够资格与梵（万物的本源）合一。 |
| 在世俗中一切都有，在胜义中都没有。 | 按平常的看法（世俗），什么都有；按最究竟的看法（胜义），都没有。 |
| 被执取的色蕴、受蕴、想蕴、行蕴、识蕴。 | 人紧抓不放的五样东西：身体（色）、感受（受）、认知（想）、意志（行）、意识（识）。 |
| 对头顶的光明施行总制，就能见到成就者。 | 把心完全集中（总制）在头顶的光上，就能见到修行有成的人（成就者）。 |

两种写法都可以，看哪种顺：「平常话（术语）」或「术语（平常话）」。一部书里同一个术语只用一种译法，并且和这部书「常见的词」里的写法一致。

一句里堆了三个以上术语，说明这一句要拆开重写，不是加三个括号。

## 5. 每章的「这一章在讲什么」

- 两三句，最多四句，放在经文前面。读者看完就知道这一章的来龙去脉，再去读正文。
- 写这一章**实际讲了什么**：谁在场，谁问了什么，答了什么，讲了哪个故事，结论是什么。不写感想，不写「本章意义深远」。
- 章里「你」「我」「我们」指谁不明显的，在末尾补一句。
- 不用还没解释过的术语；非用不可就在句子里顺手解释。
- 中文一份、英文一份，意思相同。英文是独立写的英文，不是中文的硬译。
- 单章的书不写（书的简介已经在页面最上面）。

## 6. 每部书的「读之前先知道这几件事」

给没背景的人看的几条问答，四到八条，每条一个小标题加一段话。常用的几条：

1. **这是一本什么书**：谁的经典，大约什么时候、在哪里出现，讲的是什么。
2. **是谁在说话**：全书的说话人和听的人；「我」「你」「他」各指谁。
3. **当时的背景**：不知道就读不懂的那一点处境。
4. **读的时候会卡住的地方**：这部书特有的说话方式，如重复、偈颂、一连串的否定、发誓。
5. **常见的词**：五到十个反复出现的词，各一两句白话解释。只收这部书里真的反复出现的。
6. **从哪里读起**：多章的书给一个入门顺序。

写法：

- 事实只写通行的说法；有争议或只是传统说法的，写「传统上说」「一般认为」。拿不准的不写。年代写约数。
- 不加立场：用「佛教徒相信」「穆斯林相信」「这部经说」，不写成本站的断言。
- 不夸：不写「最伟大」「智慧的巅峰」。
- 中文、英文各一份，条数相同。

## 7. 英文版

英文版贴着原文字面译，不加括号。中英两版对着看，就知道中文里哪些是补的。英文的导读和「读之前先知道」和中文意思相同，用平常的英文写。

## 8. 重写旧译文的流程

1. **先做样板**：一部书先挑最难懂的一小段（十段左右）重写，给用户看口气，定了再铺开。
2. **一部一部做**，先做有人搜、又卡在术语上的：心经、金刚经、薄伽梵歌、瑜伽经。法华经、楞伽经最长，排后面。
3. **改在面板书库**（`personal-dashboard/client/public/books/local/<id>.json`），再 `node scripts/import-dashboard.mjs` 导入；不手改 `content/`。只改白话，不动原文和罗马转写，这样英译的指纹不会失效。
4. **先写「常见的词」再译**：一部书的术语译法先定下来，译文照着用。
5. **每部书做完**跑 `npm run check`，再从头到尾读一遍，用下面的清单查。

## 9. 自查清单

- [ ] 随便抽一段，没背景的人读一遍能说出它在讲什么。
- [ ] 每段开头看得出是谁在说话。
- [ ] 术语第一次出现有白话解释，写法和「常见的词」一致。
- [ ] 补的字都在圆括号里；括号里没有评论。
- [ ] 段数和原文一样，没有合并、拆开、跳过。
- [ ] 没有替经文辩护或批评的话，没有夸大的形容。
- [ ] 背景说明里没有拿不准的事实。
- [ ] 中英两版条数相同，英文里没有中文，中文里没有英文（原词的罗马转写除外）。
